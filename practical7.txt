PRACTICAL 7: Dynamic Memory Allocation and Memory Leak Detection

Aim:
To develop a C program using malloc(), calloc(), realloc(), and free(), and detect memory leaks using Valgrind.

Program:
dynamic_memory.c

Compilation:
gcc -Wall -Wextra -g dynamic_memory.c -o dynamic_memory

Execution:
./dynamic_memory

Functions demonstrated:
1. malloc() - dynamically allocates memory.
2. calloc() - dynamically allocates and initializes memory to zero.
3. realloc() - changes the size of previously allocated memory.
4. free() - releases dynamically allocated memory.

Valgrind command:
valgrind --leak-check=full ./dynamic_memory

Final Valgrind Result:
in use at exit: 0 bytes in 0 blocks
All heap blocks were freed -- no leaks are possible
ERROR SUMMARY: 0 errors from 0 contexts

Memory Leak Demonstration:
The free(calloc_ptr) statement was temporarily commented out.
Valgrind detected:
20 bytes in 1 blocks are definitely lost.

The original program was then restored and tested again successfully.
